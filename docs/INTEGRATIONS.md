# Integration plan

| Service | Intended use | Status |
|---|---|---|
| AG Grid | Enterprise data grids for operational records | Planned for data-heavy screens |
| Elasticsearch | Optional search/indexing; PostgreSQL remains fallback | Implemented; configure URL and optional API key |
| Render | Web/API deployment | Requires account and environment configuration |
| Postman | API and Sandbox test collections | Collection to be authored alongside stable endpoints |
| Bryntum | Procurement and delivery timelines | Verify product/license/API availability |
| APIMatic | SDK generation from OpenAPI | Requires account and stable OpenAPI definition |
| Channel3 | Product/catalogue intelligence | Verify API fit and access |
| Astropods | Evaluate documented product capability | No assumed integration |
| KERNEL | Evaluate documented product capability | No assumed integration |
| PayPal | Sandbox orders, capture and webhooks | Implemented; requires Sandbox app credentials |
| Gemini | Invoice explanations and image-based invoice extraction | Implemented through Gemini OpenAI-compatible endpoint; requires API key and model |
| Gmail | OAuth2 transactional email for verification, reset, and invitations | Implemented; requires OAuth2 credentials and sender mailbox |
